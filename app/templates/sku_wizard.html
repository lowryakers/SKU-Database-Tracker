Bulk Upload BOM Files

Upload CSV or Excel files containing Bills of Materials. The system will automatically match them to SKUs.

Supported formats: .csv, .xlsx, .xls
Required columns: SKU Code (or similar), Ingredient Name (or similar)
Optional columns: Amount, Source, Unit, CAS Number
Note: You need to create SKUs first (with at least SKU code) before uploading BOMs. The system matches BOM entries to existing SKUs.
Bulk Upload Artwork Files

Upload artwork files (JPG, PNG, PDF). The system will auto-match them to SKUs based on filename.

Tip: Name your files with the SKU code (e.g., "SKU001_label.jpg") for automatic matching.
